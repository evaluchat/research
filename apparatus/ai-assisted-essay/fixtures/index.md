# Synthetic Essays fixtures

These fixtures contain no classroom or identifiable participant data. They are
small, deterministic examples for checking that a Canvas implementation keeps
the minimum student workflow intact across apparatus profiles.

- [`profile-matrix.json`](profile-matrix.json) — canonical, gate-off, AI-off,
  canvas-action-off, and tracking-off resolved configurations;
- [`events.json`](events.json) — synthetic event shapes showing what is retained
  with tracking on and what is omitted when tracking is disabled.

Fixtures are test inputs, not evidence or efficacy claims. Real evidence must
carry consent/anonymisation checks and the apparatus/configuration provenance
described in [`../ai-assisted-essay.en.md`](../ai-assisted-essay.en.md).
