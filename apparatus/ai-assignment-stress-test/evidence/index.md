# Apparatus — AI Assignment Stress Test (evidence collection)

One evidence collection per apparatus. No evidence contributions yet.

When evidence arrives, each contribution is a mini-bundle under
`apparatus/ai-assignment-stress-test/evidence/<slug>/` (see the
[evidence-bundle template](../../../templates/evidence-bundle/index.md)). It must link a
pre-existing [research question](../../../theory/ai-assignment-stress-test-validity.en.md) and record `apparatus: {id, version, configuration}` and
`canvas: {version}` in provenance, including the pinned model set used for the probe.

The collection accepts assignment-level, teacher-approved reports only. It contains no raw learner
material, student process telemetry, authorship verdicts, or AI-use detections. Any published
assignment artefact must be appropriately anonymised and its consent and retention record included
in provenance.
