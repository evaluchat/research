# Theory

Theoretical constructs and background for the openrigor research program. Theory in this catalog is explicitly unproven (`status: draft`) until supported by evidence.

## Theory

- [CAMDLE — constrained AI-mediated dialogic writing (theory, unproven)](camdle.en.md) — the proposed learning design: drafting support conditional on prior dialogic contribution. A research agenda, not an efficacy claim.

## Research Question

- [Threshold calibration — what counts as sufficient dialogic contribution?](threshold-calibration.en.md) — the central research question: how the drafting-unlock threshold varies by task type, proficiency level, language background, and learner strategy (status: open).
- [AI assignment stress-test validity — when can task probes identify what an assessment still measures?](ai-assignment-stress-test-validity.en.md) — when standardised AI task probes provide valid, reliable, and useful evidence about what an assignment can still measure with AI available (status: open).
- [Revision-tracking validity — when can process metrics provide fair evidence about recorded Canvas AI assistance?](revision-tracking-validity-question.en.md) — whether a frozen revision-metrics protocol can distinguish a known Canvas event fairly and usefully, without becoming authorship or integrity detection (status: open).
- [Synthetic question for repository layout contract testing](synthetic-question.en.md) — invented question for v0.8 private GitHub repository layout validation only (status: open; not a real programme).
