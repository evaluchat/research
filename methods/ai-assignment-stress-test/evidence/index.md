# Method — AI Assignment Stress Test (evidence collection)

One evidence collection per method. No evidence contributions yet.

When evidence arrives, each contribution is a mini-bundle under
`methods/ai-assignment-stress-test/evidence/<slug>/`, copied from this version's
[evidence-template/](../evidence-template/index.md). It must link a
pre-existing [research question](../../../theory/ai-assignment-stress-test-validity.en.md)
and record `method: {id, version, levers, canvas}` in provenance, including the pinned model set.

The collection accepts assignment-level, teacher-approved reports only. It contains no raw learner
material, student process telemetry, authorship verdicts, or AI-use detections. Any published
assignment artefact must be appropriately anonymised and its consent and retention record included
in provenance.
