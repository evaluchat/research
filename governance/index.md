How evidence is produced and how claims are reviewed. Ladder = production; protocol = review. Shared evidence roles are catalog convention; each method version pins its own payload.

- [The contribution ladder — how teachers contribute to research](contribution-ladder.en.md) — observation → documented experience → structured experiment → replication/challenge → synthesis → finding.
- [Claim governance — review protocol for findings](review-protocol.en.md) — finding tiers, approval gates, review procedure, and challenge rules.
- [Shared evidence roles — how every method files a run](evidence-roles.en.md) — observation/inference separation and provenance `method: {id, version, levers, canvas}`. Payload shape is pinned by `methods/<id>/evidence-template/`.
- [GitHub research workspaces — threat model](github-research-threat-model.en.md) — privacy and security threat model for v0.8 private GitHub research workspaces: leak vectors, OAuth/token threats, rotation failure modes, and verification obligations.
